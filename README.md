## ⚡ Overview

A performance-first developer portfolio engineered with **Astro**, **Tailwind CSS v4**, and **Lenis** inertia scrolling, styled with an authentic dark Apple iOS glassmorphism aesthetic.

- **Framework:** [Astro](https://astro.build) (Static Islands Architecture)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com) + Custom Glass Primitives
- **Typography:** PT Serif & DM Sans
- **Telemetry:** Real-time GitHub contributions chart & activity streaks
- **Deployment:** [GitHub Pages](https://warhammered.github.io/) via GitHub Actions CI/CD

---

## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/warhammered/warhammered.github.io.git
cd warhammered.github.io

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build static output for production
npm run build
```
